# Name map: obfuscated identifier -> port name

The decompiler shows the obfuscated identifiers of the original as
`_SafePkg_N` (packages), `_SafeCls_N` (classes) and `_SafeStr_N` (members),
the SWF itself holds `_-XY` strings. The port gives everything a real name
and records the original one next to the declaration, in a comment.
This file collects those comments (generated by `tools/namemap.py`).

Names that were not obfuscated (`Level`, `GamePanel`, `update`...) are kept
as they are and not listed. To find the port of an obfuscated name, search
this file. To see the evidence, open the ported file and the decompiled one.
